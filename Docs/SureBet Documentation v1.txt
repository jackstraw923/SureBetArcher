1.  System Overview
SureBet Pro automates value detection, Kelly-sized position management, and portfolio risk control across 10+ sports. The core philosophy: treat every bet as a quantitative investment requiring an edge verified by two independent tests before any capital is allocated.

1.1  Design Principles
•	Two-gate filter — model probability must beat the no-vig implied probability (edge), AND expected value must exceed 5.24%. Clearing one gate alone is not sufficient.
•	Fractional Kelly — 1/4 Kelly on every pick. Aggressive enough to compound, conservative enough to survive drawdowns.
•	Portfolio cap — combined daily Kelly exposure cannot exceed 20% of bankroll. A single high-edge day cannot blow up the account.
•	Audit-first architecture — every pick enters a lifecycle log as IDENTIFIED. The daily picks sheet is derived from those logs, not the other way around.
•	Settle before you bet — each run scores yesterday's bets before outputting today's picks. P&L is always current before new positions open.

3.  Value Filter & Position Sizing
3.1  Two-Gate Value Filter
Every candidate bet must independently clear both gates. Clearing one alone is insufficient.

Gate	Condition	Constant	Purpose
Gate 1 — Expected Value	model_prob × decimal_odds − 1 > EV_GATE	EV_GATE = 5.24%	Minimum expected return per dollar wagered
Gate 2 — Edge	model_prob > no_vig_implied_prob	Must be positive	Model must outperform the book's fair line
Sanity Cap	EV must not exceed EV_CAP	EV_CAP = 200%	Rejects implausibly large edges — likely data errors

No-vig implied probability: no_vig_prob = (1/odds) / overround, where overround = sum of all side implied probabilities in the market.

3.2  Kelly Position Sizing
Stage	Formula	Note
Full Kelly	f* = (b × p − (1−p)) / b    where b = decimal_odds − 1	Standard Kelly criterion
Quarter Kelly	raw_kelly = f* / 4	Conservative fractional Kelly — meaningfully reduces variance
Portfolio Scale	sf = min(1,  BANKROLL_CAP / Σ raw_kelly)	Scales all bets proportionally when combined Kelly exceeds cap
Scaled Kelly	scaled_kelly = raw_kelly × sf	Final stake as fraction of bankroll

•	BANKROLL_CAP = 0.20 — combined daily Kelly cannot exceed 20% of bankroll. Scale factor triggers on most days with 50+ picks.
•	Kelly can be zero — even when EV passes the gate, if decimal odds are very short the Kelly formula returns zero.
•	Mailing list use: publish the Kelly column only. Subscribers multiply by their own bankroll for a dollar stake. Risk $ is for internal paper trading.

4.  Position Lifecycle & Logs
4.1  Position State Machine
Every bet is assigned a deterministic position_id at creation and moves through a defined state machine. Terminal states accept no further transitions.

State	Meaning	Valid Next States
IDENTIFIED	Flagged by model — not yet placed	OPEN · EXPIRED · VOID
OPEN	Placed with bookmaker	LIVE · VOID
LIVE	Game currently in progress	HEDGED · CLOSED · SETTLED · VOID
HEDGED	Opposite leg placed to lock profit	SETTLED · VOID
CLOSED	Cashout taken before game ends	Terminal
SETTLED	Game complete — result recorded	Terminal
EXPIRED	Never placed before game start	Terminal
VOID	Game cancelled or postponed	Terminal

position_id format: sport|game_date|home_team|away_team|value_side|bookmaker — deterministic, so re-running the script never creates duplicate log entries.

10.  Known Limitations
ℹ️  Documented, expected limitations — not bugs. Each is a calibration or feature item for a future phase.

•	Small sample — ~300 settled bets to date. Model parameters need 500+ per sport before calibration is meaningful.
•	Spread edge-to-prob — 3%/pt and 1.5%/pt priors in calc_spread_total_bets() are literature estimates, not derived from this dataset.
•	Soccer draw distribution — draw probability assigned at the league average rate regardless of team styles or match context.
•	Tennis HFA — +25 Elo point home court advantage is a literature default, not calibrated to this dataset.
•	MLB preseason — preseason odds are lower-quality signal. Treat model outputs as directional only until March 27.
•	Challenger time parsing — depends on consistent time_raw formatting in spreadsheet. Verify if TBD appears unexpectedly.
•	No live betting — LIVE position state is tracked but no live-line action is taken automatically.
•	No Kelly floor — very small Kelly values are not rounded up to a minimum bet. Risk $ may show amounts below practical book minimums.
