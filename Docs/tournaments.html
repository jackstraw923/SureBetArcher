TOURNAMENTS

Championship probability and round survival rates from 50,000 Monte Carlo simulations. Updated each morning as the brackets evolve. Path-priced, not headline-priced.

How this works: The model runs 50,000 single-elimination tournament simulations using current team strength ratings (Pythagorean for NBA/NHL, Elo for tennis). Each simulation plays out the full bracket respecting draw position — capturing path dependency that series odds ignore. Results show championship probability, finals reach rate, and semis reach rate. Read the methodology →
